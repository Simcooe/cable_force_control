# 四绳机构与三轴理想位置驱动

本目录可以独立运行。机构来自 `../structure/model_new_visual_aligned.slx`，四绳的安装走线、锚点和卷筒参数取自旧版 `sim/v1/baseline` 实际运行的模型。双击 `baseline.command` 即可在默认浏览器中循环播放三轴小动作。播放器支持暂停、拖动进度和全屏。需要旋转查看静态装配时，运行 `./baseline.command view`，按 **1** 看整机，按 **2** 看前端。

## 在 MuJoCo 中看完整定位

运行 `./baseline.command playback`，默认打开最新一次完整记录，在原生 MuJoCo 三维窗口中循环播放。按 **P** 暂停或继续、**R** 重播、**1** 看整机、**2** 看前端。可以拖动旋转和缩放。画面按保存的关节位置、速度和仿真时间重放，绳形按这些姿态重新计算；张力和力矩数值以原运行记录为准。

指定本次 −45°、+4 mm 的记录：

```sh
./baseline.command playback --run results/pose_minus45deg_4mm_unlimited_20261120_191811
```

`pose` 完成后自动保存关节记录和结果。想在一次新仿真结束时立即看画面，可运行 `./baseline.command pose --angle -45 --length 4 && ./baseline.command playback`。双击入口仍打开带收放绳示意的小动作视频。

## 给定机构角度和伸出量

在本目录运行 `pose`，只需输入相对装配零位的目标弯折角（度）和目标伸出量（mm，伸出为正）。每次命令从装配初态开始。

```sh
./baseline.command pose --angle -0.2 --length 0.05
./baseline.command pose --angle -45 --length 7 --plan-only
```

几何算法用起点和终点的绳长差换算三轴终点，向位置驱动器一次下达蓝、绿、轴向三个编码器目标。蓝、绿各按自己的绳长差换算；轴向按紫绳换算，橙绳随轴反向收放。大角度时，算法在独立模型副本中分段跟踪导向接触，以免终点绳长发生绕圈跳变。这些查询仅用于求绳长。

位置电机自行按速度、加速度限制起停，默认自动计算时长，也可指定 `--duration`。机构的实际运动路径由动力学产生。`--plan-only` 只输出终点指令；正常执行会报告保持 20 ms 后的机构位姿与误差。

### 怎样读回放

上方是前端 CAD 和 MuJoCable 求出的实际绳形。为看清内部走线，画面将套管半透明显示。左下示意图将弯折角和伸出位移都放大 200 倍，灰色轮廓表示初始位置，数字显示实际值。右下两根色条显示相对初始位置的净收绳量，正值为收、负值为放。“收绳”和“放绳”文字表示当前运动方向。回程中，紫绳边放边回到零，橙绳边收边回到零。

去程 0.28 s、保持 0.02 s，再回程 0.28 s、保持 0.02 s。全程按 0.075 倍速播放约 8 秒。编码器回零时，滑块可能仍有位移。可直接打开 `replay/demo.mp4`；默认入口复用已生成的视频，当前模型、网格、驱动或回放代码变化后会重新生成。

```sh
./baseline.command replay
./baseline.command check
./baseline.command demo
./baseline.command move --blue 0.10 --green -0.08 --axial 0.12 --duration 0.28
```

`move` 从装配零位起步，三个输入是电机编码器的绝对目标角度（度），时长以秒计。到位后再保持 20 ms。`demo` 执行示例动作，再将三个电机转回零位。输出包括实际编码器角度、每根绳的收放量、峰值张力、驱动力矩、弯折角和滑块关节位移。收绳为正、放绳为负。滑块关节正方向为回缩。

## 安装走线

下表按出绳点到锚点排列。括号中的导向允许接触、脱离和重新接触。R2、R3、R5 使用同一份 V 槽剖面网格，L1 至 L5 使用圆柱导向面。

| 绳 | 经过的导向 | 末端 |
| --- | --- | --- |
| 蓝 | R2 → L2 →（L3）→（L4）→（Solid46 窗口边缘） | Solid46 上的蓝绳中心线锚点 |
| 绿 | R3 → L1 → L2 | Solid46 上的绿绳中心线锚点 |
| 橙 | R5 → 橙绳前端导向眼 →（L4） | 滑块上的 A3 |
| 紫 | R3 入口眼 → R3 → 导柱入口眼 → L3 →（L4）→ L5 → 回程眼 | 滑块上的 A4 |

出绳点固定在机架参考位置。L5、Solid46 边缘和紫绳回程眼随弯折件运动，A3、A4 随滑块伸缩。继承的安装参数包括轴向刚度 EA = 8000 N、蓝绿各 0.0001 N 的初始预张力、橙绳 0.2 mm 的初始松量，以及各绳原有的导向摩擦与绕绳余量。

## 理想位置电机

| 编码器正转 | 有效卷筒半径 | 绳端线速度 / 加速度上限 |
| --- | --- | --- |
| 蓝轴收蓝绳 | 4.76 mm | 3 mm/s，6 mm/s² |
| 绿轴收绿绳 | 4.76 mm | 3 mm/s，6 mm/s² |
| 轴向收紫、放橙 | 10.01 mm | 1 mm/s，2 mm/s² |

橙、紫卷筒刚性连接在同一根轴上，两根绳分别读取该轴的实际角度，以相反绕向更新自由长度。电机走五次位置轨迹，每个 50 µs 物理步按质量矩阵和当前绳载荷求出三轴所需力矩，由 MuJoCo 执行器施加。弯折和滑块的运动由动力学求解。命令超过速度、加速度或安装放绳余量会在起步前报错。三轴采用无限矩理想位置驱动，各轴所需峰值力矩记录在 `peak_torque_Nm`。

## 滑块与套管摩擦

Solid34 滑块与随动套管 Solid42 共用移动刚体，分别以 42、367 个凸分块对 Solid46 的 672 个凸分块产生接触。各分块随当前 CAD 参考系安装，并共用 `src/carriage.py` 中的接触参数。MuJoCo 用椭圆摩擦锥、两个切向方向与滑动摩擦系数 **0.2** 求解各接触点。刚体组保留轴向移动，并增加两个被动横移及两个被动倾斜自由度。轴向另有 **0.35 N·s/m** 黏性阻尼；关节干摩擦为零。接触参数和凸分块沿用旧 baseline，系数尚未按实物辨识。

`move` 和 `demo` 的 `carriage_contact` 输出记录活动接触步数、同时接触点数峰值、法向力总和峰值、最大数值穿入量，以及带符号的轴向摩擦峰值。轴向摩擦由各点切向力在滑块上的合力投影得到，正号沿回缩方向；其中不含轴向黏性阻尼。法向力与摩擦峰值分别在整段轨迹上统计。

当前验证保留 Simscape 刚体、惯量和重力，支架固定，探头在自由空间运动。工件接触、球铰和压簧加载属于另一阶段。卷筒回到零位后，被动滑块仍可有残余位移。

## 修改与重建

| 文件 | 用途 |
| --- | --- |
| `model/routing.xml` | 四绳安装数据。包含各导向和眼环的刚体归属、局部坐标、锚点、穿绳顺序、可脱离标志、插件与电机参数。改走线优先改这里。 |
| `model/carriage_hulls.xml`、`src/carriage.py` | 三个零件的接触凸分块、支承自由度、摩擦参数及测力。更新这三个零件的 CAD 形状时也需更新对应碰撞包络。 |
| `model/meshes/guide_v.msh` | R2/R3/R5 共用的路由网格。其余 176 个网格来自当前项目的 STEP。 |
| `model/simscape.json`、`src/slx.py`、`src/assembly.py` | 机构装配快照、SLX 连接读取器、MJCF 生成器。运行加载的文件是生成的 `model/assembly.xml`。 |
| `src/kinematics.py` | 根据机构关节目标和当前走线换算一组三轴终点角度。 |
| `src/drive.py`、`scripts/model.py` | 三轴理想位置驱动，以及查看、动作、构建和校验入口。 |
| `model/routing_reference.npz` | 从旧模型冻结的几何对照，包括三组姿态、双精度出绳点和锚点、插件路径长度、每绳按弧长取的 129 个路径点。布局 XML 记录了源模型的 SHA-256。 |

改走线或 MJCF 生成规则后运行 `./baseline.command build`。它从本地数据重建并进行装配、位置保持检查。`./baseline.command check` 另外比较旧版参考绳形。主动改动设计时，这项对照可显示与旧安装的差异。

改 Simscape 刚体、参数或 STEP 后，运行 `./baseline.command import`，通过 MATLAB R2023a 和 FreeCAD 重建装配与网格，再应用 `routing.xml` 中的走线。导入器会将 SLX 中的 CAD 路径绑定到当前 `structure/`。MATLAB 的 STEP 读取器在装配时曾给出 -8005、-8006 诊断；零件外观网格由 FreeCAD 生成。

## 小动作验收

- 几何对照覆盖零位、单独弯折 −0.003 rad、单独移动滑块 −0.02 mm。逐一比较四根绳的出绳点、锚点、整条绳的采样点和长度，并检查 MuJoCable 路由状态。
- 示例去程的实测收放量为蓝 +0.008308 mm、绿 −0.006646 mm、橙 −0.020965 mm、紫 +0.020965 mm。启用套管摩擦后，去程末端弯折 −0.04231°，滑块伸出 0.01995 mm。去程 6000 步中有 5973 步存在活动支承接触，轴向摩擦峰值 +0.01367 N，法向力总和峰值 0.16737 N，最大数值穿入量 0.03214 mm。
- 对照使用相同初态、电机命令、碰撞几何、重力和轴向阻尼，仅在内存中把这两个碰撞组的 `condim` 改为 1，只求法向接触。该次去程滑块伸出 0.02117 mm，轴向接触摩擦为零。
- 单独从零位执行 `./baseline.command move --blue 0 --green 0 --axial -1.35 --duration 0.9`，橙绳收 0.235855 mm、紫绳放 0.235855 mm。橙绳收过初始松量，峰值张力约 0.00607 N。以上均为本机仿真读数。

本地环境使用 Python 3.15、MuJoCo 3.17.0、Apple Silicon 和 Apple clang++。重建 Python 环境和插件可执行：

```sh
python3.15 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python scripts/build_plugin.py
./baseline.command check
```
